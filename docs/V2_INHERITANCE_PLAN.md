# V2 继承计划

## 目标

V2 是稳定的 Address Visualizer 版。V3 将通过只读分析识别其中经过验证的教学概念、交互行为和计算规则，再以适合多 Lab 平台的边界重新设计。

## 原则

- V2 始终只读，不在其目录内修改、生成或提交文件。
- 不复制 V2 源码、Git 历史、环境目录、缓存、PDF 或构建产物。
- 继承行为与经验，不默认继承现有模块边界或界面结构。
- 每项继承内容都应有明确来源、V3 归属和验收标准。
- 先将规则实现为纯逻辑并用 `unittest` 验证，再接入 PySide6 GUI。

## 后续步骤

1. 只读盘点 V2 的用户流程、术语、输入约束和可视化行为。
2. 建立候选继承项清单，区分“保留、调整、淘汰、待定”。
3. 将保留项映射到独立 Lab 及其 controller、view model 和 widget。
4. 为纯逻辑行为补充 V3 自有测试和验收说明。
5. 经确认后分阶段实现，不进行整仓复制。

本计划尚未执行，当前没有完成任何 V2 功能迁移。
