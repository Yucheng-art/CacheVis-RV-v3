# 路线图

## 阶段 0：项目初始化

- 建立独立 V3 仓库。
- 建立协作约束、架构说明、交接上下文、继承计划和决策记录。
- 不开发业务功能。

## 阶段 1：范围与接口设计

- 只读分析 V2 的稳定行为。
- 确定首批 Lab、学习目标和验收标准。
- 定义平台层与 Lab 的边界及公共接口。

## 阶段 2：纯逻辑与测试

- 按 Lab 实现独立领域逻辑。
- 使用 `unittest` 覆盖关键规则、边界条件和状态转换。
- 保持逻辑层不依赖 PySide6。

## 阶段 3：GUI 集成

- 为每个 Lab 建立独立 controller、view model 和 widget。
- 接入平台导航与共享视觉规范。
- 验证教学流程、交互反馈和可访问性。

## 阶段 4：质量与发布准备

- 完成回归测试、文档和打包检查。
- 排除环境目录、缓存、PDF 和构建产物。
- 依据明确的发布决策创建版本；本阶段规划不代表已授权创建 tag 或发布。
