# CacheVis-RV V3

CacheVis-RV V3 规划为一个面向计算机组成与 RISC-V Cache 教学的多实验室交互式可视化平台。

项目目前处于初始化阶段，仅建立项目管理约束、产品与技术规划以及文档骨架，尚未开始业务功能开发。

## 版本定位

- V1：软件著作权归档版，仅作只读参考。
- V2：稳定的 Address Visualizer 版，仅作只读参考。
- V3：面向多个独立 Lab 的平台版，是后续开发目标。

## 当前状态

当前仓库不包含从 V1 或 V2 复制的源码，也不代表规划中的 Lab、界面或教学功能已经实现。后续工作将遵循“纯逻辑 → `unittest` → GUI”的顺序逐步开展。
